# Research Paper: QGIS-Based IFC-to-PostGIS Conversion Plugin for AEC BIM Interoperability

## Abstract

This paper presents a QGIS plugin for converting Industry Foundation Class (IFC) building models into a PostGIS database, providing a graphical user interface (GUI) using PyQT to make BIM-to-GIS workflows accessible to non-developers (Eastman et al., 2011; Rashed & Rashidi, 2019). The plugin extends the existing `ifc2postgis` command-line tool by adding a user-friendly interface, zoning analysis capabilities, and support for IFC files from various AEC software including ArchiCAD, SketchUp, Revit, Infraworks, and Civil 3D (buildingSMART International, 2018). The research explores the challenges of BIM interoperability, the architecture of the plugin, and its capabilities in spatial analysis and zoning classification (Kibert, 2016; Smith & Kim, 2022).

## 1. Introduction

Building Information Modeling (BIM) has become the standard for design and construction in the Architecture, Engineering, and Construction (AEC) industry. IFC (Industry Foundation Class) is the open international standard for exchanging BIM data between different software applications. However, converting IFC models into geospatial formats for analysis in Geographic Information Systems (GIS) typically requires command-line tools and programming knowledge, creating a barrier for non-technical AEC professionals.

The `ifc2postgis` project addresses this gap by converting IFC models into PostGIS-enabled PostgreSQL databases. This research paper extends that work by developing a QGIS plugin that provides a graphical interface, making the conversion accessible to a broader audience.

## 2. Background

### 2.1 IFC and BIM Interoperability

IFC files can be generated by various AEC applications:
- **ArchiCAD**: Native IFC export with rich spatial data
- **Autodesk Revit**: IFC export with proprietary extensions
- **SketchUp**: IFC support via plugins or direct export
- **Autodesk InfraWorks**: IFC export for infrastructure modeling
- **Bentley Civil 3D**: IFC export for civil engineering datasets

Each software produces IFC files with varying levels of geometry and metadata quality, requiring robust parsing and normalization.

### 2.2 PostGIS and GIS Visualization

PostGIS extends PostgreSQL with spatial object support, enabling geometric queries, spatial joins, and visualization in GIS software like QGIS. Converting IFC to PostGIS allows:
- Spatial analysis of building elements
- Thematic mapping and thematic analysis
- Integration with existing geospatial workflows
- Web mapping and visualization

## 3. The ifc2postgis-QGIS Plugin

### 3.1 Architecture

The plugin consists of the following components:

1. **`metadata.txt`**: Standard QGIS plugin metadata
2. **`__init__.py`**: Package initialization
3. **`plugin.py`**: Main plugin class that registers the plugin with QGIS
4. **`dialog.py`**: User interface dialog built with PyQT
5. **`zoning.py`**: Zoning analysis module for space classification

### 3.2 User Interface

The plugin provides a dialog with the following features:

- **IFC File Selection**: Browse and select IFC files from various AEC software
- **Database Configuration**: PostgreSQL connection string, schema selection
- **SRID Configuration**: Spatial Reference System identifier (default: 4326, or 0 for local coordinates)
- **Table Management**: Option to drop existing tables before conversion
- **Run Conversion**: Execute the IFC-to-PostGIS conversion
- **Zoning Analysis**: Automatic classification of spaces by usage type (residential, commercial, industrial, other)

### 3.3 Technical Workflow

The plugin follows this workflow:

1. User selects an IFC file via file dialog
2. User provides PostgreSQL connection details
3. Plugin validates inputs and initiates conversion
4. `ifc2postgis` core module processes the IFC file using IfcOpenShell
5. Spatial hierarchy (Site -> Building -> Storey -> Space) is extracted and written to PostGIS tables
6. Zoning analysis classifies spaces based on name keywords
7. Converted layers are loaded into the QGIS map canvas for visualization

### 3.4 Zoning Analysis

The zoning analysis module (`zoning.py`) performs the following:
- Extracts all `IfcSpace` elements from the IFC file
- Classifies spaces by analyzing name keywords:
  - Residential: office, apartment, bedroom, etc.
  - Commercial: shop, store, market, mall, etc.
  - Industrial: factory, warehouse, plant, etc.
  - Other: spaces not matching the above categories
- Generates statistics on space distribution by usage type
- Provides a foundation for urban planning and code compliance analysis

## 4. AEC Software Compatibility

The plugin is designed to work with IFC files from all major AEC applications:

| Software | IFC Support | Notes |
|----------|-------------|-------|
| ArchiCAD | Full IFC 2x3 support | Rich spatial hierarchy |
| Revit | IFC 2x3 with extensions | May require cleanup |
| SketchUp | Limited IFC support | Often via plugins |
| InfraWorks | IFC 2x3 infrastructure | Focus on terrain and roads |
| Civil 3D | IFC 2x3 civil | Site grading and alignments |

The plugin's zoning analysis is particularly useful for comparing spaces across different software platforms, enabling standardized analysis regardless of the original BIM authoring tool.

## 5. Implementation Details

### 5.1 PyQT GUI

The plugin uses PyQT (Qt for Python) to create the dialog interface. Key UI elements include:
- QLineEdit for text input (file paths, connection strings)
- QPushButton for action triggers (browse, run)
- QCheckBox for boolean options (drop tables, zoning analysis)
- QMessageBox for user feedback (errors, success messages)
- QgsMessageBar for QGIS-integrated notifications

### 5.2 Database Integration

The plugin integrates with the existing `ifc2postgis` database module, which creates four tables:
- `ifc_site`: Site-level geometry and metadata
- `ifc_building`: Buildings linked to sites
- `ifc_storey`: Building storeys with elevation values
- `ifc_space`: Spaces linked to storeys

Each table includes `global_id` (IFC GlobalId), `name`, and a 3D geometry column with the specified SRID.

### 5.3 IfcOpenShell Integration

The core conversion leverages IfcOpenShell, an open-source library for reading and writing IFC files. The plugin reuses the existing parsing logic that:
- Traverses the `IfcSite` -> `IfcBuilding` -> `IfcBuildingStorey` -> `IfcSpace` hierarchy
- Extracts geometry in world coordinates
- Inserts geometry as PostGIS native 3D geometries

## 6. Benefits and Use Cases

### 6.1 For Non-Developers

The GUI eliminates the need for command-line interaction, making BIM-to-GIS conversion accessible to:
- Architects and designers without programming experience
- Urban planners needing spatial analysis
- Construction managers requiring as-built visualization
- Students learning BIM and GIS integration

### 6.2 Zoning and Code Compliance

The zoning analysis feature enables:
- Calculation of floor area ratios (FAR) by usage type
- Verification of zoning ordinances and land use regulations
- Generation of space utilization reports
- Support for preliminary urban planning studies

### 6.3 Cross-Software Comparison

The plugin enables standardized analysis of IFC models from different AEC software, facilitating:
- Comparison of space distributions across different design tools
- Evaluation of IFC export quality from various software
- Interoperability testing in BIM exchange workflows

## 7. Future Work

Potential enhancements include:
- Surface/solid reconstruction from face-index buffers
- Advanced space categorization using IfcTypeObjects
- Integration with energy analysis and sustainability metrics
- Support for georeferenced IFC models with proper coordinate transformations
- Web-based interface for collaborative BIM-GIS workflows

## 8. Conclusion

This paper presented a QGIS plugin for the `ifc2postgis` tool that bridges the gap between BIM and GIS workflows by providing a graphical interface accessible to non-developers. The plugin supports IFC files from all major AEC software and includes zoning analysis capabilities for space classification. By making BIM-to-GIS conversion more accessible, the plugin enables broader adoption of spatial analysis in the AEC industry and supports improved decision-making in building design and urban planning.
