description=Turn an IFC building model into PostGIS layers you can query, style and analyse in QGIS.
    Choose an IFC file, enter a PostGIS connection URL, pick a schema and SRID, then click Convert IFC.
    Sites, buildings, storeys and spaces are added to the current project as separate layers.
about=The plugin makes BIM data usable as spatial data without leaving QGIS.
    It converts each spatial level of an IFC model into a table row with its IFC GlobalId,
    name, 3D geometry and a link to the parent element, so you can join the tables,
    count rooms per storey or style spaces by room type.
    Conversion writes to ifc_site, ifc_building, ifc_storey and ifc_space in the target schema.
    An optional room analysis groups spaces into Laboratory, Office, Corridor, Men,
    Ladies and Other and shows the totals in the dialog.
    Use SRID 4326 for georeferenced models or 0 for local Cartesian coordinates.
