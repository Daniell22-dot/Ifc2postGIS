--- FREQUENTLY ASKED QUESTIONS ---

Q1: "Does this work with [specific IFC file]?"
A1: "Yes - we tested with SOE.ifc which has 105 spaces. Any valid IFC 2x3 file should work. If you have a problematic file, we can troubleshoot."

Q2: "Do I need PostgreSQL installed?"
A2: "Yes, PostGIS is required. The tool creates 4 tables in your database. Alternative: we could discuss SQLite+GeoPackage future work, but PostGIS is the current design."

Q3: "Can I use this with Revit/ArchiCAD/SketchUp files?"
A3: "Absolutely. The plugin accepts any valid IFC file. We've tested with SOE.ifc which works. Your firm's IFC files should be compatible as long as they follow IFC 2x3 schema."

Q4: "Is this production-ready?"
A4: "v0.1 - functional for conversion and zoning analysis. Gaps identified for v1.0: solid georeferencing, batch processing, enhanced zoning compliance. Roadmap available."

Q5: "What if my IFC file has errors?"
A4: "The plugin validates inputs and reports errors clearly. IfcOpenShell is robust but may skip problematic elements. The drop/recreate option helps with clean conversions."

Q5: "Can I get the research paper published?"
A5: "The paper is available at research_paper.md. It follows APA 7th edition and can be submitted to journals like Automation in Construction, Building and Environment, or Journal of Construction Engineering."

Q6: "Do I need programming skills to use this?"
A6: "No - that's the whole point! The PyQT GUI eliminates command-line interaction. However, Python skills help for customization and extending the zoning analysis."

Q7: "What's the license?"
A7: "MIT - free for commercial and academic use. No royalties, no restrictions on modification."

Q8: "What's the difference between ifc2postgis CLI and the QGIS plugin?"
A8: "Same core functionality. CLI is for automation/scripting. Plugin is for graphical, interactive use. Both share the parser.py and database.py modules."

Q9: "Can I contribute to the project?"
A9: "Yes! MIT license. Issues, bug reports, feature requests welcome. The gaps document identifies what needs work. Pull requests welcome."

Q10: "What Python version is required?"
A10: ">=3.13,<3.16 per pyproject.toml. We're targeting Python 3.13 specifically."
